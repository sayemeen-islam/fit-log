# 🏋️‍♂️ Fit Log

Fit Log is a dark, responsive workout companion that helps users explore workouts, create a daily plan, save workouts, and track workout progress

## 🔗 Live Link

[**View Fit Log Live →**](https://fit-log-track.vercel.app/)

## 🛠️ Technologies Used

- Next.js
- React
- TypeScript
- Tailwind CSS
- React Context API
- LocalStorage
- React Icons
- React Toastify

## ✨ Key Features

- **Workout Library:** Browse 12 workouts with categories, equipment, duration, calories, and ratings.
- **Workout Details:** View detailed workout specifications and step-by-step instructions for each exercise.
- **Today's Plan:** Add workouts to today's plan, mark workouts as done, remove individual workouts, and sort workouts by duration, calories, or rating.
- **Saved Workouts:** Save workouts for later, view workout details, remove individual workouts, and sort workouts by duration, calories, or rating.
- **Dynamic Workout Metrics:** View total exercises, duration, and calories, with metrics updating based on the selected Today's Plan or Saved section.
- **Persistent Data:** Today's Plan and Saved Workouts are stored in LocalStorage and remain available after a page reload.
